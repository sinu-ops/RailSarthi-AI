What RailSarthi delivers

Not just location — understanding. Our pipeline combines real-time RailRadar telemetry, predictive XGBoost modeling, and a LangGraph reasoning agent that explains every recommendation with evidence.

TELEMETRY

Live Train Status

Real-time delay, station position, and next halt drawn from RailRadar API — cached for 5 minutes to protect your API quota.

PREDICTION

Delay Forecasting

XGBoost regression predicts cascading stop-by-stop delays using distance covered, temporal seasonality, and previous delay propagation.

AGENT

Journey Copilot

LangGraph agent answers travel questions by selecting and calling tools — comparing trains with supporting evidence, never inventing reasons.

Agentic Journey Copilot

Ask in plain language: "I'm travelling Mumbai to Delhi tomorrow — which option is better?" The agent selects tools (live status, delay prediction, reliability score), compares results, and explains the recommendation with evidence.

  • Tool selection — picks appropriate backend endpoints
  • Evidence grounding — cites model outputs and historical observations
  • No hallucination — explanations come only from retrieved data, not LLM imagination

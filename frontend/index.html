Features

Three integrated layers: telemetry from RailRadar, predictive ML from historical patterns, and a reasoning agent that explains its recommendations using real data.

Telemetry

Live Train Status

Real-time delay, station position, and next halt from RailRadar API — cached for 5 minutes to protect quota.

Prediction

Delay Forecasting

XGBoost regression predicts cascading stop-by-stop delays using route distance, temporal seasonality, and previous delay propagation.

Agent

Journey Copilot

LangGraph agent answers travel questions by calling tools — comparing trains, explaining recommendations with evidence, never inventing reasons.

Design approach

This page is built for the railway journey context: warm cream and amber tones evoke the golden-hour glow of Indian rail journeys; Playfair Display carries editorial authority; Inter delivers readable data. No purple. No sloppy card-kit. One orchestrated reveal on load, then quiet discipline everywhere else.

Palette: bone (#F8F4EC), amber (#B45309), rust (#C2410C), charcoal (#1C1917), stone (#57534E). Layout: left-aligned editorial column, max 880px, responsive to mobile. Motion: only the hero reveal and hover lifts on feature cards.
